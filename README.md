# هم‌آوا — نسخهٔ دانشجو برای Android

یک نسخهٔ دانشجویی و موبایل‌محور بر اساس فایل HTML ارسالی. کنترل‌های مدیریتی HTML اصلی (بارگذاری آهنگ، ویرایش فراداده، حذف آهنگ درسی و خروجی‌گرفتن HTML) عمداً در این نسخه وجود ندارند.

## قابلیت‌ها

- کتابخانهٔ درس محلی و ماندگار؛ آهنگ‌های دانلودشده پس از قطع اینترنت نیز قابل پخش‌اند.
- همگام‌سازی کتابخانه با مخزن عمومی GitHub؛ همگام‌سازی اول، فایل‌ها را دانلود می‌کند و همگام‌سازی‌های بعدی تغییرات را بررسی می‌کنند.
- پخش فایل‌های صوتی، جابه‌جایی در آهنگ، جلو/عقب ۵ ثانیه، تکرار و کنترل صدا و سرعت.
- نمایش متن LRC هم‌زمان با پخش و لمس یک مصرع برای رفتن به زمان مربوط.
- ضبط صدا با میکروفون و کدگذاری واقعی MP3 (LAME؛ 128 kbps)، نگه‌داری محلی و امکان اشتراک‌گذاری با Android Share Sheet / Telegram.
- تیونر کروماتیک زنده با نمایش نت، فرکانس و انحراف سنت.
- رابط فارسی راست‌به‌چپ با سبک مینیمال و رنگ سبزآبی متناسب با هم‌آوا.

## اتصال به GitHub

در برنامه روی چرخ‌دنده بزنید و نشانی یک مخزن عمومی را وارد کنید. این شکل‌ها پشتیبانی می‌شوند:

- `https://github.com/OWNER/REPO`
- `https://github.com/OWNER/REPO/tree/main/songs`

بدون فایل فهرست، برنامه فایل‌های صوتی مستقیم در مسیر تعیین‌شده را پیدا می‌کند (MP3, M4A, AAC, WAV, OGG, FLAC, OPUS). برای نمایش عنوان بهتر می‌توان نام فایل را به شکل `Artist - Song title.mp3` گذاشت. اگر فایلی مانند `Song title.lrc` با نام پایهٔ یکسان وجود داشته باشد، به عنوان متن زمان‌بندی‌شده استفاده می‌شود.

### گزینهٔ پیشنهادی: `catalog.json`

برای کنترل دقیق نام، خواننده، آلبوم، سال، سبک، یادداشت و مسیر متن، فایلی به نام `catalog.json` در ریشهٔ همان پوشه قرار دهید:

```json
{
  "songs": [
    {
      "id": "lesson-01",
      "title": "عنوان آهنگ",
      "artist": "نام خواننده",
      "year": "2024",
      "album": "نام آلبوم",
      "genre": "پاپ",
      "note": "نکته‌ای برای تمرین",
      "audio": "lesson-01.mp3",
      "lyrics": "lesson-01.lrc"
    }
  ]
}
```

`audio` و `lyrics` مسیرهای نسبی از پوشهٔ تنظیم‌شده‌اند. به‌جای `lyrics` می‌توانید `lyricsText` هم قرار دهید و متن LRC را مستقیماً در JSON بنویسید. برای متن زمان‌بندی‌شده، هر خط را این‌طور بنویسید:

```text
[00:12.50] مصرع اول
[00:18.00] مصرع دوم
```

در نسخهٔ فعلی، مخزن باید عمومی باشد و دسترسی API عمومی GitHub استفاده می‌شود؛ مخزن خصوصی و توکن احراز هویت هنوز پشتیبانی نشده است. برای فایل‌های بزرگ یا تعداد زیاد آهنگ‌ها، پوشه‌بندی درس‌ها با `catalog.json` توصیه می‌شود.

## ساخت APK

فایل APK کامپایل‌شده در این محیط ساخته نشد: این محیط Android SDK / build-tools نصب‌شده ندارد و دسترسی شبکهٔ ساخت هم برای دریافت آن‌ها در دسترس نیست. سورس کامل پروژه آماده است و workflow گیت‌هاب هم همراه فایل‌هاست تا APK را بسازد.

### ساخت در Android Studio

1. Android Studio را نصب کنید و پوشهٔ `hamava-android` را باز کنید.
2. اجازه دهید Android Gradle Plugin و SDK platform 35 نصب/همگام‌سازی شوند.
3. از منوی **Build → Build APK(s)** استفاده کنید؛ اسکریپت `gradlew` نسخهٔ Gradle موردنیاز را در اولین اجرا دریافت می‌کند.
4. خروجی debug معمولاً در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

### ساخت با GitHub Actions

پروژه را به یک مخزن GitHub آپلود کنید. Workflow موجود در `.github/workflows/build-apk.yml` با اجرای دستی یا push، APK دیباگ را می‌سازد و به‌صورت artifact منتشر می‌کند.

## نکته‌های فنی

- فایل‌های درسی و ضبط‌ها در فضای خصوصی خود برنامه ذخیره می‌شوند؛ با پاک‌کردن داده‌های برنامه یا حذف برنامه ممکن است از بین بروند.
- اشتراک‌گذاری با Telegram از طریق منوی اشتراک‌گذاری Android انجام می‌شود. خود برنامه پیام یا فایل را بدون اقدام دانشجو ارسال نمی‌کند.
- ضبط و تیونر به اجازهٔ میکروفون نیاز دارند. پخش آهنگ هنگام ضبط با هدفون توصیه می‌شود تا صدای آهنگ دوباره داخل ضبط نیفتد.
- نسخهٔ فعلی از آهنگ‌های داخل مسیر ریشه/پوشهٔ مخزن و فایل فهرست `catalog.json` استفاده می‌کند؛ مدیریت هنرجو برای آپلود یا ویرایش محتوای درس در این برنامه وجود ندارد.

## مجوز کد و کتابخانهٔ MP3

برای کدگذاری مستقیم MP3، این پروژه از `TAndroidLame` استفاده می‌کند: https://github.com/naman14/TAndroidLame . آن کتابخانه تحت GPL-3.0 منتشر شده است؛ متن GPL در فایل `COPYING` قرار دارد. قبل از انتشار عمومی APK یا انتشار نسخهٔ تجاری، شرایط GPL و حقوق فایل‌های موسیقی/متن را بررسی کنید.
